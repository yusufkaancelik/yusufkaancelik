### `CH 01` — FiveM · QBCore

The **ykc** series: 30 resources built on QBCore for my own server. Most are drop-in replacements for the stock qb scripts.

| | |
|---|---|
| **ykc-phone** | Full-featured in-game smartphone; metro, bus and music apps plug into it |
| **ykc-police** | Duty, cuffing, dispatch, speed radar, evidence, MDT tablet, Bolingbroke jail |
| **ykc-metro** · **ykc-bus** | NPC metro & bus lines, Akbil cards, driver jobs, LS Kart / LS Rota phone apps |
| **ykc-hud** | Status icons, speedometer, minimap, compass, drag-and-drop layout editor |
| **ykc-inventory** · **ykc-banking** | Modern inventory UI (clothing, bag, wallet) + banking that reads cards from the wallet |
| **ykc-fuel** | Pump nozzle & hose, auto-connect on either side, EV charging, jerry cans |

→ [See all of them on the site](https://yusufkaancelik.me/#fivem)
